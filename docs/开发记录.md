## 1. 项目概述

一个**自包含的 DeepSeek Harness（dsh）桌面应用**：用 Electron 原生窗口承载官方 `dsh web` 引擎，目标用户**无需安装 Node.js**。

在官方 Web UI 基础上新增了三项设置功能：

1. **用户**：显示当前 DeepSeek API Key（脱敏）、余额、一键跳转充值；
2. **背景**：导入图片作为背景，半透明覆盖主界面与侧边栏（在浅色/深色/跟随系统之上）；
3. **关于**：创作者 Adrain Lin、创作时间 2024-11-04、版本号、检查更新（带进度条下载安装）。

## 4. 架构总览

```
Electron 壳 (desktop/main.js)
  └─ 用便携 Node 拉起 dsh web --no-open --port 0 --patch <运行时 patch>
       └─ 从 dsh 打印的 stdout 抓取「带 token 的鉴权 URL」→ 窗口加载它
            └─ dsh web 引擎（官方未修改）
                 ├─ Host 插件：webServer.register() 注册 /api/desktop/*
                 └─ Client 插件：注册 settings.section / settings.general.item
```

**引擎模式**（`main.js` 里 `DSH_LAUNCH`，默认 `bundled`）：

- **bundled**（默认、自包含）：引擎在 `resources/dsh`（npm 装的 `@deepseek-ai/dsh`），
  便携 Node 在 `resources/node/node.exe`；插件以「包」形式复制进
  `resources/dsh/node_modules/@adrainlin/dsh-desktop-plugin`。
- **npx**：`npx @deepseek-ai/dsh web`（开发用，需本机 Node）。

## 5. 三项功能的实现要点

### Host（`plugin/src/host.js`，纯 JS 无需构建）

- `webServer.register({ kind:'exact', path, handler })` 注册路由；
- `credentials.resolve('DEEPSEEK_API_KEY')` 读 API Key；
- 路由：
  - `GET /api/desktop/about` → 创作者/时间/版本（版本用 `DSH_DESKTOP_VERSION` 或插件默认）；
  - `GET /api/desktop/user` → 脱敏 key + DeepSeek 余额（`GET https://api.deepseek.com/user/balance`）+ 充值地址 `platform.deepseek.com/top_up`；
  - `GET /api/desktop/update/check` → 已废弃（更新改为走 Electron IPC，见下）。

### Client（`plugin/lib/client.js`，手写 factory 形式 bundle）

- 注册 `settings.section`：`user`（用户）、`about`（关于）；注册 `settings.general.item`：`background`（背景）。
- 背景：图片转 data URL 存 `localStorage`，注入 `<style>` 把图片放 `html,body` 背景，
  再用 `theme.overrideTokens('desktop-background', {...})` 把 `--dsw-alias-bg-*`、
  `--dsw-specific-sidebar-fill` 覆盖成半透明（rgba alpha ~0.22–0.34），让图片透出来（约 75% 透明）。
- 检查更新：走 `window.desktopApp.checkUpdates()` / `installUpdate()` / `onUpdateProgress()`（IPC）。

### 检查更新（Electron 主进程，非插件）

- `main.js` 里 `DEFAULT_UPDATE_URL = 'https://api.github.com/repos/Adrain-Lin/deepseek-harness-desktop/releases/latest'`；
- 读 GitHub Release API：`tag_name`（去掉 `v` 前缀）当版本号，`assets` 里找 `.exe` 当下载地址；
- 用 `isNewer()` 做语义化版本比较；有新版 → IPC `installUpdate` 下载 .exe（进度事件）→ `shell.openPath` 启动安装。

## 6. 关键接口速查（都验证过）

- Host 服务：`webServer.register()`、`credentials.resolve()`、`settings.register()`。
- Client 插槽：`settings.section`（list，登记 `{id,order,label}`，owner props `{close}`）、
  `settings.general.item`（list，登记 `{id,order,label}`，owner props 空）。
- 主题服务 `theme`：`setFontSize(px)`（12–17）、`overrideTokens(source, {token:{light,dark}})`、`getTheme()`。
- Client bundle 格式：`window.__ModuleLoader__.load({id, factory(require){...; return module.exports}})`；
  `require('react')` 命中 shell 种子词；`exports.inject=['slots']` + `exports.apply=apply`。
- 插件 patch 格式（`cordis.patch.yml`）：`- insert: [{id, name: '@adrainlin/dsh-desktop-plugin'}]`。

## 7. 踩坑记录（重要，别重蹈）

1. **Electron 必须 ≥44**（自带 Node 24）。Electron 33 自带 Node 20，缺 `node:zlib.createZstdDecompress`、`node:module.stripTypeScriptTypes`，dsh 直接起不来。
2. **不能用 `ELECTRON_RUN_AS_NODE=1` 跑 dsh**：会打印 URL 后立即退出；改用「打包便携 Node + spawn」。
3. **`--patch` 是启动器标志**，必须放在 app 标志（`--no-open/--host/--port`）之前。
4. **插件 `name` 必须用裸包名**：`file://` URL 只能加载 Host，Client 半部不会被扫进 `__DSH_BOOT__`。
5. **插件必须放进 `$DSH_HOME/profiles/node_modules/`**：dsh 的 `healProfilesModuleFallback` 只链接 dsh 依赖闭包，不链 out-of-tree 插件（由 `main.js` 的 `ensurePluginInstalled` 复制）。
6. **electron-builder 26 的 `extraResources` 会跳过源根目录的 `node_modules`**（`filter.js` 硬编码 `relative==="node_modules"` 返回 false），所以 `from` 要指向 `resources/dsh/node_modules`。
7. **`npm install file:` 生成 junction，electron-builder 会丢链**，改用 `Copy-Item`。
8. **Electron/electron-builder 二进制下载走 npmmirror 镜像**（GitHub 直连超时）：`ELECTRON_MIRROR` + `ELECTRON_BUILDER_BINARIES_MIRROR`。
9. **独立 `DSH_HOME`**（`<userData>/dsh-home`），避免与已有 `~/.dsh` 冲突。
10. **默认端口用 0**（让 dsh 自选空闲端口），避免与用户手动 `dsh web`（3080）冲突。
11. **加载带 token 的鉴权 URL**，不能加载裸 `http://127.0.0.1:PORT`（会命中「authentication required」）。
12. **Windows PowerShell 5.1 读「无 BOM 的 UTF-8」会乱码**：
    - `.ps1` 脚本文件必须带 **UTF-8 BOM**；
    - 脚本里读 JSON 要用 `[System.IO.File]::ReadAllText()`（显式 UTF-8），别用 `Get-Content`（默认 GBK）——否则会把中文「桌面端」读乱并破坏 package.json。
13. **打包产物/依赖不入库**：`node_modules/`、`desktop/resources/`、`dist/` 已在 `.gitignore`。
14. **API Key 不进安装包**：key 存 `%APPDATA%\deepseek-harness-desktop\dsh-home\.credentials.yaml`（运行时、每用户独立），打包资源里无凭据。
15. **背景图不能只存 `localStorage`**：引擎用 `--port 0` 每次随机端口，而 `localStorage` 按 origin（协议+主机+端口）隔离，重启后端口变了就读不回上次的图（表现为「只保留一次、关掉就消失」）。解决：背景 data URL 改走 Electron IPC 存到 `userData/background` 文件（`desktop:bg:get/set/clear`，`preload.js` 暴露 `window.desktopApp.getBackground/setBackground/clearBackground`），Client 端 `getStoredBg/setStoredBg/clearStoredBg` 优先 IPC、浏览器模式回退 localStorage。

## 9. 构建 / 发版流程

```powershell
# 打包（自包含）
cd E:\Deepseek Harness_Work\creat_app\packaging
.\build.ps1

# 一键发版（改版本号 → 打包 → 打印发 Release 步骤）
.\release.ps1 0.1.2
```

发版步骤：脚本改 `desktop/package.json` 版本号 → 打包 → 复制成 `DeepSeek.Harness.Setup.<版本>.exe`
→ 去 GitHub `releases/new`，Tag 填 `v<版本>`，上传该 exe → Publish。
之后已装用户点「关于 → 检查更新」即可自动发现并更新。
